# 📝 To-Do List Application (Python)

A simple and beginner-friendly **Command-Line To-Do List App** built using Python.  
This project allows users to add tasks, set due dates, mark tasks as completed, delete tasks, and view pending tasks.

Perfect for beginners learning:
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- Basic date handling

---

## 🚀 Features

- ➕ Add new tasks  
- 📅 Enter **due date** for each task  
- 👀 View **all tasks** with status  
- ❗ View **pending tasks only**  
- ✅ Mark tasks as completed  
- 🗑 Delete tasks  
- 🔁 Simple menu-driven interface

## 🧠 How It Works

### When adding a task:
- The program asks for a task name.
- Then it asks for a **due date** in `YYYY-MM-DD` format.

### Example: 
Enter the task: Study Python Enter the due date (YYYY-MM-DD): 2025-01-20 Task added successfully with due date!
